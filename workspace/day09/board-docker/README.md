# 미니 게시판 (Mini Board App)

JavaScript를 활용하여 동적 DOM 조작 및 데이터 CRUD 패턴을 학습하기 위해 제작한 미니 웹 게시판 애플리케이션입니다.

---

## 1. 프로젝트 개요

* **프로젝트명**: day07 JavaScript 심화 - 미니 게시판
* **학습 주제**: JavaScript DOM 조작, 배열 데이터 관리, 이벤트 처리, 기능 명세 작성 및 부분 수정 실습
* **기술 스택**: HTML5, CSS3 (Vanilla CSS), JavaScript (ES6+)

---

## 2. 주요 기능

1. **게시글 목록 렌더링 (`renderPosts()`)**
   * 자바스크립트 내 `posts` 배열 데이터를 바탕으로 HTML `<ul>` 요소 내에 동적으로 `<li>` 게시글 항목을 생성 및 출력합니다.

2. **게시글 추가 기능**
   * 제목 입력 후 '추가' 버튼을 누르면 새로운 고유 ID와 함께 `posts` 배열에 데이터가 추가됩니다.
   * 유효성 검사: 제목이 5글자 미만이거나 빈 값일 경우 경고 메시지를 띄우고 추가를 제한합니다.
   * 추가 완료 시 입력창은 자동으로 초기화됩니다.

3. **게시글 삭제 기능**
   * 게시글마다 삭제 버튼이 제공되며, 삭제 전 사용자 확인(`confirm`) 절차를 거칩니다.
   * 삭제 확정 시 `posts` 배열에서 해당 게시글이 제거되고 목록이 다시 출력됩니다.

4. **디자인 시스템 적용**
   * Claude DESIGN.md 규격을 준수하여 크림 캔버스 배경, 코랄 포인트 색상, Google Fonts (EB Garamond & Inter) 폰트 스택을 적용했습니다.
