HTML 기본 뼈대

모든 HTML 문서는 아래 구조로 시작합니다. 실제 코드를 그대로 보여주는 것이 설명 그림보다 낫습니다.

standard_html.html 
<!-- 문서 형식 : HTML5 -->
<!doctype html>
<html lang="ko">
  <head>
    <meta charset="UTF-8" />
    <title>HTML 기본 구조 페이지</title>
  </head>
  <body>
    <!-- 화면에 보이는 내용 -->
    <h1>가장 큰 제목</h1>
  </body>
</html>
IMAGE

이미지 태그

  • src : 이미지 파일의 경로
  • alt : 이미지가 안 보일 때 대신 읽어줄 설명
  • width / height : 크기 (CSS로 옮기는 것을 권장)

alt 속성은 반드시 작성하는 습관을 들인다

링크 태그로 이동하기

a 태그는 anchor의 약자로, href 속성에 이동할 주소를 적습니다. 다른 사이트로도, 같은 폴더의 파일로도 이동할 수 있습니다.
