# 디버깅 및 문제 해결 (S7)

코드 오류를 진단하고 해결 방법을 안내합니다.

## 디버깅 절차

1. 에러 메시지 또는 증상 확인
2. 관련 코드 분석
3. 원인 설명 (한국어로)
4. 수정 방법 제안 (코드 diff 포함)
5. 유사 실수 방지 팁 제공

## 주의사항

- 정답을 바로 주기보다 **힌트를 먼저 제공**합니다.
- "왜 이런 오류가 발생하는지" 원리를 설명합니다.
- 학습자가 직접 수정해볼 수 있도록 유도합니다.
- 코드 수정이 필요하면 사용자 확인 후 진행합니다.

## 작업 절차

1. 사용자가 보고한 에러 메시지/증상을 확인합니다.
2. 관련 코드 파일을 분석합니다.
3. 원인을 한국어로 설명합니다.
4. 힌트를 먼저 제시하고, 필요 시 수정 코드(diff)를 제안합니다.
5. 유사 실수 방지 팁을 제공합니다.
