[ 4회차 진도]
1. HTML에 CSS를 적용하는 방법
	(1) 외부 스타일 시트
		: CSS코드를 HTML파일 안이 아니라, 완전히 별도의 .css 파일로 분리해서 작성하고, HTML에서는 그 파일을 '연결'만 하는 방식을 의미한다.
	(2) 내부 스타일 시트
		: <head> 태그 안에 <stlye> 태그로 CSS를 작성한다.
	(3) 인라인 스타일
		: 꾸며줄 태그에 style 속성을 추가하여 CSS를 적용한다.

2. 외부 스타일 시트 방식을 통해 HTML에 적용하는 방법
	: HTML파일의 <head>태그 안에 <link> 태그를 활용하여 외부 css 파일이 어디 있는지 알려주고 연결하는 태그이다.
	[ <link> 태그 사용법 ]
	<head>
		<link rel='stlyesheet' href='파일이름.css'>
	</head>

	- rel(relationship, 관계) 
	: 연결하는 파일이 '어떤 종류' 인지 알려준다.
	: CSS파일을 연결 시에는 항상 'stlyesheet'라고 작성한다.
	- href(hyperlink reference)
	: 연결할 파일의 경로(위치)를 작성하고 대상을 적는다.

3. 외부 스타일을 사용하는 이유
	: 외부 스타일 시트의 가장 큰 장점은 '여러 HTML 파일이 하나의 CSS파일을 공유'할 수 있기 때문이다.
	: 하나의 CSS파일을 HTML이 공유하여 스타일을 적용하기 때문에 유지보수가 편해진다.

4. CSS 선택자의 종류
	: 선택자란, 이 스타일을 어떤 태그에 적용할 것인가를 지정하는 부분이며, 지정 방식에 따라 태그/클래스/아이디/하위 선택자 4종류로 나뉜다.

	(1) 태그 선택자
	: 태그 이름을 그대로 선택자로 쓰며, 같은 이름의 태그 전부에 스타일이 적용
	
	(2) 클래스 선택자
	: 특정 태그 안에 속성으로 class='이름'을 붙인 태그들에게만 스타일을 적용한다.
	: 같은 클래스 이름을 여러 태그에 중복 사용할 수 있다.

	(3) 아이디 선택자
	: 특정 태그 안에 속성으로 id='이름'을 붙인 태그에만 스타일을 적용한다.
	: HTML 파일 내에서 단 하나뿐인 태그를 지정하는 선택자이다.
	: 아이디 이름을 중복해서 사용할 수 없다.
	
	(4) 하위 선택자(자손 선택자)
	: 특정 태그 안에 들어있는 또 다른 태그만 선택하여 스타일을 적용한다.
	: 하위 선택자에 태그 이름 작성시, 선택자 2개를 띄어쓰기로 나열한다.

5. 박스 모델(box model)
	: HTML의 모든 태그는 화면세어 '네모난 상자'로 취급되며, 이 상자는 바깥에서 안쪽으로 margin -> border -> padding -> content 4개 층으로 구성된다.

	(1)margin : 태그와 다른 태그 사이의 바깥 여백
	(2)border : 태그의 테두리 선 자체(두께/선 모양/선 색상)
	(3)padding : 테두리와 content 사이의 안쪽 여백
	(4)content : 실제 글자나 이미지가 채워지는 가장 안쪽 공간

6. div태그
	: <div>는 아무 의미도, 기본 스타일도 없는 '빈 상자 태그'이며, 여러 태그를 하나로 묶어서 그룹으로 다루기 위해 사용한다.
	: <div>는 오직 '그릇'역할만 한다. 그 안에 h1, p, ui등 다른 태그들을 넣어서 하나의 덩어리로 묶어두는 용도로 사용한다.
		ex)
		<div class='이름'>
			<h1>제목</h1>
			<p>내용</p>
		</div>
	: 위와 같이 여러 태그에 대해서 똑같은 CSS를 적용 시 <div> 태그로 묶어서 하나로 처리한 후, 동일한 CSS를 적용한다.

7. <div>와 <span>의 차이
	: <div>는 항상 새 줄에서 시작하고 가로 폭 전체를 차지하는 블록(block)요소이고, <span>은 줄바꿈 없이 필요한 만큼만 자리를 차지하는 인라인 요소이다.
	: <div>는 줄 하나 전체를 차지하고, <span> 문장 속에 요소를 차지한다.

8. <div> 중첩
	: <div> 태그 안에는 다른 <div>를 포함해서 어떤 태그든 자유롭게 여러개, 여러 겹으로 넣을 수 있다.
	: 전체 구조를 단계별로 묶어 나갈수 있다. 이렇게 태그 안에 태그가 겹겹이 들어있는 구조를 중첩이라고 한다.
