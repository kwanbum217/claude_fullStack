1.JSON 이해
	: JSON(JavaScript Object Notation)이란 데이터를 주고받을 때 사용하는 표준 텍스트 형식으로, Key(이름)와 Value(값)의 쌍으로 이루어져있다.
	: 서버와 브라우저는 대부분 JSON형태로 데이터를 주고받는다.
	: JSON은 문법이 JS객체와 거의 똑같이 생겨서 JS에서 다루기 편하다.
		ex) JSON은 국제 표준 택배 상자 규격과 같다. 어느 나라(서버, 프로그래밍 언어)에서 보내든 이 규격(JSON 형식)에 맞춰 포장하면, 받는 쪽(어떤 언어든)에서 동일하게 뜯어볼 수 있다. 

2.기능을 명세로 정리해서 요청하기

3. 미니 게시판 기본 구조 만들기 - 목록 출력
	: 게시글 데이터를 화면에 목록 형태로 보여주는 기능을 실습하려고 한다.
	: 5일차에 배운 DOM 조작을 활용하여, JS 배열 안에 데이터를 화면의 li태그 등으로 반복해서 출력하려고 한다. 이 기능이 오늘 만들 게시판의 가장 기본적이 기능이라고 할 수 있다.
	: 서버없이 '미리 적어둔 메모 목록'을 화면에 그대로 옮겨 붙이는 것과 같다. 아직은 DB나 서버의 내용을 다루지 않았으므로, JS 코드. 안에서만 존재하는 데이터로 취급하려고 한다.

	[ 목록 출력 실습 프롬프트]
Prompt: 
script1.js에 posts라는 배열을 만들고, 그 안에 id와 title을 가진 게시글 데이터 2~3개를 미리 넣어줘. 그리고 renderPosts()라는 함수를 만들어서, 이 posts배열을 화면의 목록 영역(ul)에 li태그로 하나씩 출력하도록 해줘. 페이지가 열리면 자동으로 renderPosts()가 실행되도록 해줘.

4. 게시글 추가 기능 만들기
	: 입력창에 제목을 적고 버튼을 누르면 posts 배열에 새 게시글이 추가되고 화면이 다시 그려지는 기능을 만들려고 한다.
	: 추가 버튼에 클릭 이벤트를 걸어서 입력값을 읽고, 배열에 push한 뒤 목록을 다시 렌더링하는 흐름이다. '데이터를 바꾸고 -> 화면을 다시 그린다'는 패턴이 진행된다.

	[ 게시글 추가 기능 실습 프롬프트 ]
입력창에 제목을 입력하고 '추가'버튼을 누르면, posts배열에 새 게시글이 추가되고 목록이 다시 출력되로록 해줘. 새 게시글의 id는 기존 게시글들과 겹치지 않게 자동으로 만들어줘. 입력창이 비어있을 때는 추가되지 않고 '제목을 입력해주세요' 같은 안내가 뜨도록 해줘. 추가된 뒤에는 입력창이 다시 빈 칸으로 초기화되도록 해줘

5. 게시글 삭제 기능 만들기
	: 게시글 옆 삭제 버튼을 누르면 해당 게시글만. posts배열에서 제거되고 화면이 갱신되는 기능을 만들라고한다.

	[ 게시글 삭제 기능 실습 프롬프트 ]
각 게시글 항목 옆에 '삭제'버튼을 추가해줘.삭제 버튼을 누르면 알림(alert)창에 나에게 확인을 받고 노란색 바탕에 빨간색 굵은 글씨로 '삭제'  버튼을 누르면 해당 게시글만 posts 배열에서 제거되고, 목록이 출력되도록 해줘

6. 이미 만든 코드에 부분 수정 요청하기
	: 전체 코드를 다시 만들어달라고 하지 않고, '특정 부분만 수정할 수 있도록'수정을 요청하는 방법을 실습해보려고 한다.
	: 코드가 점점 길어질 수록 매번 전체를 다시 만들면 이전에 잘 되던 기능이 비정상적으로 진행될 위험이 있다. 따라서 수정 요청 시 '어떤 파일의, 어떤 기능을, 어떻게 바꾸고 싶은지'를 구체적으로 짚어주는게 좋다.

	[ 부분 수정 요청 실습 프롬프트 ]
기존의 script1.js파일에서 renderPosts()함수의 기능을 수정하려고 한다. 내가 원하는 기능은 입력받은 제목이 5글자 미만이라면 추가되지 않고, '제목을 5글자 이상 입력해주세요'라는 안내가 뜨도록 조건을 추가하려고 한다.
