# 코드 리팩토링 (S8)

기존 코드의 품질과 구조를 개선합니다.

## 리팩토링 기준

- 인라인 CSS → 외부 CSS 분리
- 반복 코드 제거
- 시맨틱 태그 적용
- CSS 클래스 네이밍 개선
- 주석 정리

## 주의사항

- 반드시 사용자 승인 후 수정합니다.
- 변경 전후 비교(diff)를 제공합니다.
- 기능 변경 없이 구조만 개선합니다.
- 이모지(Emoji) 사용 금지.

## 작업 절차

1. 리팩토링 대상 파일을 읽고 현재 구조를 파악합니다.
2. 위 기준에 맞는 개선 계획을 사용자에게 제안합니다.
3. 승인 후 변경 전후 diff를 제공하며 수정합니다.
4. 변경 내역과 개선 포인트를 요약합니다.
