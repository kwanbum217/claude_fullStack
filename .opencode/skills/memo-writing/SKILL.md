# 수업 메모 정리 (S1)

수업에서 배운 내용을 `memo/dayXX.txt` 형식으로 구조화된 메모로 정리합니다.

## 파일 규칙

- 파일명: `day{회차번호}.txt` (예: day05.txt, day06.txt)
- 위치: `memo/` 폴더
- 인코딩: UTF-8

## 메모 형식 (기존 스타일 준수)

```
[ N회차 진도 ]
1. 대주제
	(1) 소주제
		: 설명 내용
	(2) 소주제
		: 설명 내용

2. 대주제
	(1) 소주제
	...
```

## 주의사항

- 기존 메모 파일(day01~day04)의 번호 체계와 들여쓰기 방식을 **그대로 유지**합니다.
- 공백 2칸(2 spaces) 들여쓰기를 사용합니다.
- 설명 앞에 콜론(`:`)과 공백을 추가합니다.
- 코드 예제는 들여쓰기로 구분합니다.
- 사용자가 수업 내용을 전달하면 해당 형식으로 정리합니다.
- 기존 메모 파일의 내용은 임의로 수정하지 않습니다. 새 회차는 새 파일을 만듭니다.

## 작업 절차

1. `memo/` 폴더에서 가장 최신 메모(dayXX.txt)를 확인합니다.
2. 다음 회차 번호를 결정합니다.
3. 사용자가 전달한 수업 내용을 위 형식으로 정리합니다.
4. 저장 전 사용자에게 요약을 보여줍니다.
