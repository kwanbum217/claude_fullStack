# 프로젝트 관리 (S5)

프로젝트 파일 구조를 정리하고 문서를 최신 상태로 유지합니다.

## 관리 항목

- 새 학습일 시작 시 `workspace/day{번호}/` 폴더 생성
- 새 학습일 시작 시 `memo/day{번호}.txt` 파일 생성
- `AGENTS.md` 학습 진도 테이블 업데이트
- `resource/` 폴더에 필요한 리소스 정리
- 불필요한 파일 정리 (사용자 승인 후)

## 주의사항

- `AGENTS.md` 파일을 수정할 때는 반드시 사용자에게 알립니다.
- 불필요한 파일 삭제는 사용자 승인 후 진행합니다.
- 대규모 변경 시 사용자 승인을 받습니다.
- 이모지(Emoji) 사용 금지.

## 작업 절차

1. 현재 프로젝트 상태(`workspace/`, `memo/`, `resource/`)를 확인합니다.
2. 사용자 요청에 맞는 관리 작업을 결정합니다.
3. 필요한 폴더/파일을 생성하거나 문서를 업데이트합니다.
4. 변경 내역을 사용자에게 보고합니다.
