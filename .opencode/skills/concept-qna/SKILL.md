# 개념 설명 및 Q&A (S4)

프로그래밍 개념을 쉽게 설명하고 학습자의 질문에 답변합니다.

## 설명 원칙

- **비유 활용**: 일상적인 비유로 개념 설명 (기존 메모에서 사용된 비유 참고)
  - 예: HTML = 건물의 뼈대/구조, CSS = 인테리어/꾸미기
- **단계적 설명**: 큰 그림 → 세부 사항 순서
- **코드 예제 병기**: 설명과 함께 짧은 코드 예제 제공
- **학습 진도 고려**: 아직 배우지 않은 개념은 미리 언급하지 않음

## 참고 자료

- 비유나 예시를 만들 때 `memo/dayXX.txt`의 기존 메모를 참고합니다.
- 용어는 한국어와 영어 원문을 병기합니다. (예: 선택자(Selector))

## 작업 절차

1. 질문 주제와 현재 학습 진도를 확인합니다.
2. 일상적인 비유로 개념의 큰 그림을 설명합니다.
3. 세부 사항을 단계적으로 설명합니다.
4. 짧은 코드 예제를 함께 제시합니다.
5. 이해 확인을 위한 간단한 질문을 마지막에 던집니다.
