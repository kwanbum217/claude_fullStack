# 리소스 생성 (S6)

학습에 필요한 시각 자료를 생성합니다.

## 생성 가능 리소스

- HTML 구조 다이어그램
- CSS 박스 모델 시각화
- 웹 페이지 레이아웃 목업
- 학습 참고 이미지

## 저장 규칙

- 저장 위치: `resource/` 폴더
- 파일명: `{주제}_{설명}.{확장자}` (예: boxmodel_diagram.png)

## 주의사항

- 학습 진도에 맞는 개념만 시각화합니다.
- 이모지(Emoji) 사용 금지.

## 작업 절차

1. 시각화할 주제와 현재 진도를 확인합니다.
2. 적절한 리소스 유형(다이어그램/목업/이미지)을 결정합니다.
3. `resource/` 폴더에 저장합니다.
4. 생성된 파일 경로와 내용을 사용자에게 안내합니다.
