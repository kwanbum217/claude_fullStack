[ 5회차 진도 ]

1. JavaScript란?
: 웹페이지에서 생동감과 상호작용을 더해주는 동적인 프로그래밍 언어이다.
: 버튼을 클릭하면 화면이 바뀌고, 입력한 값에 따라 결과가 달라지는 것처럼 사용자와 상호작용하는 기능을 JavaScript로 만든다.
: JavaScript는 원래 '브라우저 안에서 웹페이지를 동적으로 만드는 언어'로 시작했지만, 지금은 서버, 앱, 프로그램까지 영역이 넓어졌다.

2. JavaScript를 활용하는 방법
	(1)HTML파일 내에서 <script> 태그로 직접 JavaScript를 작성
	
	(2)별도의 js파일을 만들어 HTML 파일에 연결

3. CSS와 JS의 차이
	:JS는 CSS와 마찬가지로 고유 태그는 없지만, CSS보다 할 수 있는 기능이 더 많다.
	:기존 요소를 조작하는 것을 넘어, 새로운 요소를 만들거나 지울 수 있다.
	:CSS는 이미 존재하는 HTML요소의 겉모습만 바꿀 수 있다. 반면 JS는 document.createElement()로 새 요소를 아예 만들어서 화면에 추가하거나, 있는 요소를 지울 수도 있다.

4. 변수(Variable)
: 변수란 값(데이터)을 저장하고 이름을 붙여 재사용 할 수 있게 해주는 저장 공간이다.
		[ 변수 선언 및 초기화 ]
		- 변수 선언 : 변수를 생성하는 작업을 의미한다.
		- 변수 초기화 : 변수에 값을 저장하는 작업을 의미한다.

		[ 변수 선언 및 초기화 방법 ]
		변수타입 변수이름 = 값;

		- 변수 타입 
		: let 또는 Const라는 키워드가 작성된다.
		: 변수타입이 let이라면 값이 바뀔 수 있는 변수를 의미한다.
		: 변수타입이 const라면 값이 고정된 변수를 의미한다.
		: 기본은 const를 사용하고, 값이 바뀔 필요가 있을 때만 let을 사용한다.

5. 함수(Function)
		: 함수란, 특수한 기능을 수행하는 명령어를 의미한다.
		: 특수한 기능을 수행하는 코드 묶음으로, 필요할 때마다 변수와 같이 함수 이름을 통해 재사용할 수 있다.
		: 함수는 특정 단어 뒤에 소괄호가 붙는다.

		- 내장 함수 : js 내에서 이미 만들어둔 명령어를 의미한다. 

		- 사용자 정의 함수 : 사용자가 직접 정의하는 명령어를 의미한다.	
		(1) 화살표 함수
		[ 화살표 함수 정의 ] 
		변수타입 변수이름 = (매개변수1, 매개변수2,...) => {
			수행문
		};

		- 매개변수 
		: 함수 실행부에서 인자로부터 전달받을 값을 저장한 후 수행문에서 해당 값들이 활용된다.
		- 수행문
		: 함수이름이 호출(실행)될 경우 실행햐야 될 코드들의 집합을 의미한다.
		
		[ 화살표 함수 실행 ]
		변수이름(인자1, 인자2,...);

		- 인자 
		: 함수 실행 시 입력받을 값으로, 매개변수에 값을 전달하여 함수를 실행하게 한다.
		: 인자의 개수 = 매개변수의 개수

		
		[ function 키워드 함수]
		function 함수이름(매개변수1, 매개변수2,...) {
			수행문
		} 

		[ function 키워드 함수 실행 ]
		함수이름(인자1, 인자2,...)

6. 이벤트(Event)
		: 이벤트란, 사용자의 동작(클릭, 입력, 스크롤)이나 브라우저에서 발생하는 사건을 의미한다.
		: addEventListener() 메서드로 특정 요소에 이벤트가 발생했을 때 실행할 함수를 등록한다.
