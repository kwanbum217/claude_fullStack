2. 입력창 + 추가 버튼 추가하기 - 입력 영역
  : 1번에서 만든 index.html에서 할 일을 입력할 칸과 추가 버튼을 생성한다.

  [ 프로세스 ]
  (1) 제목 아래에 입력칸을 하나 추가한다.
  (2) 입력칸 옆에 추가 버튼을 만드는데, 입력칸과 버튼을 하나로 묶는다.
  (3) 아직은 스타일을 적용하지 않는다.

  [ 프롬프트 ]
  기존 index.html 파일에서 제목은 그대로 두고, 그 아래에 할 일을 입력하는 <input>과 '추가' <button>을 하나의 <div>로 묶어서 생성해줘. 아직 스타일은 적용하지 않을게.

3. 할 일 목록 영역 추가하기 - 목록 영역
  : 2번까지 만든 index.html에서 할 일 목록을 표시할 영역을 추가한다.

  [ 프로세스 ]
  (1) 기존 index.html 양식을 그대로 유지하고, 입력칸과 버튼 아래에 할 일 목록을 출력할 영역을 생성한다.
  (2) 목록 영역을 생성하고, 각 목록에 대해서 순서가 없는 구조로 각각의 목록들을 출력하게 한다.
  (3) 아직 스타일은 지정하지 않는다.

  [ 프롬프트 ]
  기존 index.html 양식을 그대로 유지하고, 입력칸과 버튼 아래에 할 일 목록을 담을 <ul>을 추가해줘. 목록에 예시로 <li> 태그를 활용하여 ('예시 할 일1', '예시 할 일2')를 추가해줘. 아직 스타일은 지정하지 않는다. 

4. style.css 연결 + 기본 색상 적용 - 스타일 연결
  : 지금까지 뼈대만 있던 index.html에 css파일을 연결해서, 색상과 기본적인 여백을 적용한다.

  [ 프로세스 ]
  (1) style.css 파일을 생성한다.
  (2) index.html과 style.css를 연결한다.
  (3) 스타일은 전체 배경은 흰색, 글짜는 진한 회색, 제목은 파란색으로 설정 
  디자인 룰에 맞게 기본 색상을 지정하고, 전체적으로 간결하고 시원한 느낌이 들도록 여백과 구조를 조정한다.

  [ 프롬프트 ]
  style.css 파일을 생성하고, index.html의 head 태그 안에 <link> 태그로 연결해줘. 스타일은 전체 배경은 흰색, 글자는 진한 회색, 제목(h1)은 파란색으로 설정해줘.

5. 수정, 삭제 버튼 추가하기
  : 지금까지 목록의 각 항목(li)은 텍스트만 존재한다. 이번 단계에서는 각 항목에 수정, 삭제 버튼을 추가한다. 지금까지의 li앞에 보이던 박스 표시는 그대로 두고, 그 뒤에 실제 동작할 버튼 2개를 새로 추가하려고 한다.

  [ 프롬프트 ]
  목록의 각 li 안에 있는 텍스트를 span으로 감싸줘. 그 옆에 '수정'버튼과 '삭제'버튼을 순서대로 추가해줘. 두 버튼에 각각 edit-btn이라는 class를 붙여줘. li는 flex로 텍스트와 버튼들이 가로로 나란히 보이게 하고, 텍스트는 남은 공간을 다 차지하도록 해서 버튼들이 오른쪽 끝에 붙게 해줘. delete-btn은 빨간 계열 배경으로 구분해줘. 아직 두 버튼에 대해서 기능은 추가하지 않는다.
