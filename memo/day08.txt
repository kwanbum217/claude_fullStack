1. Git이란?
	: Git은 파일의 변경 이력을 저장하고 관리해주는 프로그램이다.
	: 'git init'은 특정 폴더를. '이제부터 Git이 관리할 폴더'로 지정하는 명령어이고, 'git status'는 지금 그 폴더 안에서 무엇이 바뀌었는지 알려주는 명령어이다.
	: 지금까지는 코드를 수정하다 실수하면 되돌리기 어려웠다. (Command + z는 몇 번만 가능하고, VS Code를 끄면 이전에 작성했던 코드 내용이 사라진다.)Git은 파일에 대해서 수정과 저장을 전부 다 대신 해주는 유용한 기능을 가지고 있다. 
		ex) 'git init'은 게임을 시작하기 전 '이 파일부터 세이브 기록을 남길게'라고 선언하는 것과 같다.
		ex) 'git status'는 '지금 세이브해야 할 변경사항이 있는지' 확인하는 것을 의미한다.
	: 'git init'은 프로젝트를 시작할 때 한번만 실행한다. 'git status'는 앞으로 습관적으로 자주 입력하게 될 명령어이다.

2. 변경사항 기록하기
	: 'git add'는 이번에 기록할 파일을 지정하는 명령어이고, 'git commit'은 지정된 파일들을 실제로 하나의 버전으로 저장하는 명령어이다.
	: git으로 기록을 남기는 과정은 항상 2단계이다, 먼저 '이번에 기록할 파일 고르기(add)'그 다음 '고른 파일을 진짜로 저장하기(commit)'진행한다.
	: 만약 5개 파일을 수정했는데 그 중 3개만 이번 기록에 포함시키는 경우를 위해 add(선택)와 commit(기록)으로 2단계를 통해 변경사항을 기록한다.

3. GitHub
	: GitHub는 Git으로 관리한 프로젝트를 인터넷에 올려두고 보관, 공유할 수 있게 도와주는 웹 서비스이다.
	: Git이 '도구'라면 GitHub	는 그 도구로 만든 결과물을 저장하는 '온라인 공간'을 의미한다.
	: 1~2번 작업은 전부 '내 컴퓨터 안'에서만 일어난다. 컴퓨터가 고장 나면 지금까지의 기록이 전부 사라진다. 따라서 GitHub에 올려두면 컴퓨터가 바뀌어도, 고장나도, 다른 사람과 함께 작업해도, 포트폴리오로 보여줄 때도 문제가 없다.
	: Git -> 로컬, GitHub -> 원격(인터넷)에 저장한다. 따라서 'Git으로 기록하고, GitHub에 올린다'로 기억하면 좋겠다.
