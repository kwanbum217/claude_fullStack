[ 1회차 진도 복습 ]
1. 웹 서비스 제작 순서
: 기획(무엇을 만들지 정하기) -> 프론트엔드(HTML/CSS/JS, 화면) -> 백엔드(눈에 안보이는 처리, 기능, 로그인과 같은 데이터를 비교) -> DB(데이터 보관하는 저장소) -> 배포(인터넷에 업로드하여 누구나 접속, 활용)

2. 바이브 코딩(Vibe Coding)
: 사람이 AI에 요청 -> AI가 코드 생성 -> 사람이 검토/수정
: 핵심은 'AI가 모든 것을 해준다'가 아니라 'AI에게 정확하게 요청을 해야한다.'가 핵심이다.

3. RCF 공식
- R(Role, 역할) : AI에게 어떤 역할을 맡길지 지정
- C(Context, 맥락) : 나의 상황과 요구사항을 구체적으로 설명
- F(Format, 형식) : 결과물을 어떤 형태로 받고 싶은지 지정

[ 2회차 진도 ]
*** 오늘의 목표 ***
1. 환경 설정 및 개발 도구 설치
2. 개발 도구 활용법 익히기

1. VS Code
: MicroSoft가 만든 '소스 코드 에디터' 
: 문법에 색을 입혀 보여주고(문법 강조), 오류를 미리 표시해주고, 터미널(cmd창)을 내장하고 있고, 확장 프로그램을 설치해 기능을 추가할 수 있는 코드 작성 전용 텍스트 에디터이다.

2. Node.js
: 원래 브라우저 안에서만 실행되던 자바스크립트(JavaScript)를 브라우저 밖(내 컴퓨터, 서버)에서 실행되게끔 해주는 '자바스크립트 실행 환경'이다.
: npm(Node Package Manager)이 자동 설치된다. 다른 사람이 만든 프로그램(패키지)을 다운받아 설치하게 해주는 패키지 관리자를 의미한다.
: 수업 시간에 활용할 Claude Code도 npm으로 배포되는 패키지이기 때문에 Node.js가 없으면 Claude Code 설치할 수 없다.

3. Git
: 파일이 변경될때마다 그 내용을 커밋(commit) 단위로 기록해서, 누가 언제 무엇을 바꿨는지 추적하고 원하는 시점으로 되돌릴 수 있는게 해주는 '분산 버전 관리 시스템'을 의미한다.

4. VS Code 설치 방법
[ Windows ]
(1) code.visualstudio.com 접속
(2) 'Download for Windows' 클릭 -> 설치파일 다운로드
(3) 설치 파일 실행 -> 라이선스 동의 -> Next 계속 클릭
(4) 설치 시 'PATH에 추가' 체크 박스는 항상 체크되어있어야 한다.
(5) 설치 완료 후 VS Code 실행

[ Mac ]
(1) code.visualstudio.com 접속
(2) 'Download for Windows' 아래 'other platforms' 클릭
(3) Mac 클릭 -> 설치 파일 다운로드
(4) Visual Studio Code 아이콘을 Applications 폴더로 드래그하기
(5) Applications 폴더에서 Visual Studio Code 설치 진행

5. Node.js 설치

[ Windows ]
(1) nodejs.org 접속
(2) 다운로드 탭(왼쪽 상단 세번째 위치)으로 이동
(3) LTS(Recommended For Most Users, 사용자에게 추천하는 모델) 버전 자동 선택 후 하단에 있는 'Windows 설치 프로그램(.msi)' 클릭 -> 설치 프로그램 다운로드 진행
(4) 설치 파일 실행 -> Next 계속 클릭(모든 옵션 기본값으로 유지)
(5) cmd창(window + r, cmd 입력 후 엔터)에서 npm -v , node -v 실행해서 버전이 출력되면 완료

[ Mac ]
(1) nodejs.org 접속
(2) 다운로드 탭으로 이동
(3) LST 버전 자동 선택 후 하단에 있는 'Mac 설치 프로그램(.pkg)' 클릭 -> 설치 프로그램 다운로드 진행
(4) 설치 파일 실행 -> Next 계속 클릭(모든 옵션 기본값으로 유지)
(5) 터미널창(cmd + 스페이스바, 터미널 입력 후 엔터)에서 npm -v , node -v 실행해서 버전이 출력되면 완료

[ VS Code의 터미널에서 버전 확인 ]
(1) VS Code 실행 
(2) ctrl + ` 단축키를 통해 VS code의 터미널 입력창 열기
(3) node -v 실행
(4) npm -v 실행

-> 버전 확인 명령어 모두 오류 시, VS Code 재실행하기
-> npm -v 실행 후 오류 발생 시, Set-ExecutionPolicy -Scope CurrentUser RemoteSigned 명령을 입력한다.

6. Git 설치
[ Windows ]
(1) git-scm.com 접속
(2) 'Install for windows' 클릭
(3) 'Git for Windows/x64 Setup.' 클릭 후 설치 프로그램 다운로드
(4) 설치 프로그램 실행 후 기본 설정으로 Next 계속 클릭
(5) 설치 완료


[ mac ]
(1) 터미널창에 git --version 입력
 
7. Claude Code 설치
(1) VS Code 실행
(2) ctrl + ` 단축키 실행하여, 터미널 창 열기
(3) npm install -g @anthropic-ai/claude-code 입력하여 실행
(4) 위의 명령어를 통해 설치 완료 후, claude 명령어를 통해 실행하여 로그인
