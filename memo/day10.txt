[ 10회차 진도 ]
1. Express 프레임워크 초기화 및 package.json 학습
  : npm init -y 명령어를 실행하여 express-board 프로젝트 초기화 및 package.json 생성
  : package.json은 프로젝트의 이름, 버전, 실행 스크립트, 설치된 의존성 패키지 정보 관리를 담당하는 설정 파일이다.

2. Express 패키지 설치
  : npm install express 명령어를 실행하여 express 프레임워크 패키지 설치
  : 설치 완료 시 package.json의 dependencies 항목에 express 패키지 정보가 자동 기록됨

3. Express 웹 서버 구축 (server.js)
  : require('express')로 express 모듈을 불러와 app 객체 생성
  : app.listen(3000, ...)을 통해 3000번 포트에서 클라이언트 요청을 대기하는 웹 서버 가동

4. 라우팅 (Routing) 및 응답 방식
  : app.get('/', ...) : 루트 접속 시 HTML/텍스트 또는 파일 서빙 처리
  : app.get('/api/hello', ...) : res.json()을 활용하여 { message: '안녕하세요' } 형태의 JSON 데이터 응답 처리

5. 정적 파일 서빙 (express.static)
  : app.use(express.static('public')) 미들웨어를 활용하여 public 폴더 안의 파일들을 정적으로 웹에 제공
  : day07 미니 게시판(index1.html, style1.css, script1.js)을 public 폴더로 연결하여 http://localhost:3000 접속 시 미니 게시판 연동 완료
