1. Express 
  : Express는 Node.js 위에서 동작하는 웹 서버 프레임워크로, 브라우저의 요청을 받아 응답을 돌려주는 백엔드 프로그램을 쉽게 만들 수 있게 해준다.
  : 3 ~ 9회차 까지의 내용은 전부 '프론트엔드'와 관련이 있는 내용으로, HTML/CSS/JS 파일들 그대로 브라우저가 읽어서 화면을 그리는 방식이었다. 하지만 실제 서비스에서는 '로그인 확인', '게시글 저장 및 조회', '데이터베이스 조회'같은 처리가 필요하다. 이런 처리는 브라우저(프론트엔드)가 아니라 별도의 서버 프로그램(백엔드)이 담당해야 하며, 그 서버 프로그램을 Node.js로 쉽게 만들 수 있게 도와주는 도구가 Express이다.
  : Express사용 시 Node.js가 설치되어 있어야 한다.
    - cmd창에서 node --version과 npm --version이 실행되는지 확인한다.

2. 프로젝트 초기화와 package.json
  : package.json은 해당 프로젝트가 어떤 이름인지, 어떤 외부 패키지를 필요로 하는지를 적어두는 설정 파일이다.
  : npm init(initiallize, 초기화하다) 명령어를 실행하면 이 package.json 파일이 자동으로 만들어진다.
  : 위와 같이 package.json 파일을 생성하고, npm install express를 실행한다면, 방금 만든 package.json에 '이 프로젝트를 express가 필요하다'는 내용이 자동으로 기록되고, 실제 express 코드는 node_modules라는 폴더안에 다운로드된다.
    ex) package.json은 요리 레시피에 적힌 '재료(package) 목록'과 같다. 목록에 'express'라고 적혀 있다면, 나중에 이 프로젝트를 다른 컴퓨터로 옮겨도 npm install 한번으로 목록에 적힌 재료를 다시 그대로 준비할 수 있다.

    [ 프로젝트 초기화와 package.json 생성 실습 프롬프트 ]
    day10/express-board 폴더에서 npm init -y 명령어를 실행해서 package.json 파일을 만들어줘. 그 다음 npm install express 명령어로 express를 설치해줘. 설치가 끝나면 package.json 파일 내용을 보여 주고, 어느 부분에 express가 기록되었는지 짚어줘.

      - npm init -y : -y 옵션은 '질문 없이 기본값으로 적용하여 생성하라' 는 것을 의미한다.
