- HTML의 태그의 개념과 구조에 대해서 이해한다.
- CSS의 개념 및 왜 필요한지 이해한다.

1. 웹 페이지 구조
: 우리가 흔히 보는 네이버, 유튜브는 사실 문서이다.
: 브라우저는 코드를 읽어서 화면으로 그려주는 번역기이다.
: 브라우저가 읽는 코드를 흔히 HTML과 CSS로 구성되어 있다.

	- HTML = 뼈대 / 골조(벽이 어디 있고, 방이 몇개 있고, 문이 어딨는지)
	- CSS = 인테리어(벽지 색깔, 가구 배치, 조명)

2. HTML의 기본 구조 태그
: HTML의 가장 기본적인 뼈대가 되는 것을 태그라고 할 수 있다.
: 태크는 이 안에 있는 내용이 무엇인지 알려주는 꼬리표를 의미한다.
	ex) 택배 '깨지기 쉬움'스티커
	
	[ 태그의 기본 생김새 ]
	<태그이름>내용</태그이름>

	- <태그이름> : 여는 태그(시작을 알린다.)
	- 내용 : 실제로 화면에 보일 내용
	- </태그이름> : 닫는 태그(/가 붙는 것에 주목한다. 여기서 끝이라는 것을 알린다.)

	[ 태그의 속성 ]
	- 태그의 속성은 태그를 통해 기본적인 기능이 아닌 추가적인 기능을 수행 시 추가하는 옵션을 의미한다.
	- 각 태그마다 속성이 서로 다르게 존재한다.

3. CSS(Cascading Style Sheets)
: <body> 태그에서 작성한 출력된 요소들을 꾸며주는 기능을 의미한다.

4. CSS가 왜 필요한가?
(1)역할의 분리
		: 과거에는 HTML 안에 글자색이나 크기를 직접 코드를 작성했기 때문에 코드가 매우 복잡했다. HTML은 구조에만 집중하고, 디자인은 CSS가 전담하도록 분리하기 위해 만들어졌다.
(2)유지보수의 편리함
		: 웹사이트의 모든 제목 색상을 파란색에서 빨간색으로 바꾸고 싶을 때, HTML파일마다 일일이 찾아갈 필요 없이 CSS 파일 하나만 수정하면 전체 페이지가 한 번에 변경된다.

5. CSS의 기본 문법 구조
		선택자 {
				속성 : 값;
				속성 : 값;
				.
				.
				.
		}

		- 선택자(Selector) : 디자인을 적용할 HTML의 태그, 아이디, 클래스 등을 지정한다.
		- 속성(Property) : 무엇을 바꿀 것인지 정한다. 
				ex) 글자색, 배경색, 너비
		- 속성값(Value) : 속성에 적용할 구체적인 내용을 적는다.
				ex)red, #ffffff, 24px

6. HTML에 CSS를 적용하는 3가지 방법
(1) 외부 스타일 시트를 적용한다.
	: CSS를 별도의 .css파일로 만든 뒤, <head> 태그 안에서 링크라여 불러온다
(2) 내부 스타일 시트를 적용한다.
	: HTML 파일 안의 <head> 태그 안에 <style> 태그를 열고 그 안에 CSS를 작성
(3) 인라인 스타일을 적용한다.
	: HTML 파일 안의 태그에 직접 style="...."속성을 작성한다.
	: 유지보수가 매우 힘들기 때문에 지양한다.
